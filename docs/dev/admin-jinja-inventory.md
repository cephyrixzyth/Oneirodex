**Current snapshot, 2026-10-14:** `oneirodex/templates/` contains no HTML files; application Python has no `render_template`, `render_template_string`, `stream_template`, Jinja filter/global registration, context processor, or template adapter. Email/offline documents use explicit escaped renderers; member/admin/styleguide documents use Python shell builders or built React shells. `frontend/shared/icons/manifest.json` is the canonical SVG catalog and only its React adapter is generated. Legacy Flask modules remain for development-time compatibility and parity tests.
