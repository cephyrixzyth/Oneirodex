# Phase H-I — the rest of the inventory, sized

> **Doc status:** Active

**Measured 2026-09-22 on `main`**, after H1 (merged + deployed) and with H2 / H3 / H4 in review. This is the sizing pass the v11 plan asked for before H-I builds anything: one row per remaining item, what it actually needs, what it waits on, and where it goes. Sizes are **S** (one sitting, one file or two), **M** (a slice: model or module + UI + tests), **L** (a phase's worth, or a decision before code).

Nothing here is scheduled by writing it down. The order at the bottom is the proposal; his interrupts outrank it.

## What the harvest already closed

The register rows below are **done** and are not in the sizing: INSP-31 (hash identify, H1a), INSP-34 (TOSEC/MAME, H1b), INSP-5 (1G1R, H1c), INSP-24 (DAT repair preview, H1f), INSP-35 (anti-cheat, H1e), INSP-36/22/37/38/39 (mods, H2a–e), INSP-40/41 (XR, H3a–b), INSP-42/43/44/6/1/45 (stores, arcade, GPU, notify, saves, assists — H4a–f). INSP-7 and INSP-33 are **documented as deferred** with their triggers (`docs/admin/libraries-and-scans.md` › *Identify sources deferred*).

Also settled while measuring: **ES-DE and Pegasus export both ship** (`GET /api/export/esde`, `/api/export/pegasus`, `routes_apis/wave8_11.py`; user docs describe the Systems *Export packs* note). The "two-doc status conflict" the plan flagged was stale — what is actually open there is INSP-9, a *third* frontend (Steam shortcuts), which is its own row below.

## Proposed order for H-I

1. **INSP-3** filter model + builder (L) → **INSP-29** smart collections (S).
2. **INSP-4** not-interested, with **INSP-21** folded in as the same enum (M+S) → **INSP-4b** (S).
3. **INSP-12** QR / short-code pairing (M).
4. A **small-wins slice**: SRV-4, GOW-3, LIGHT-3, ART-4 (four S rows, one PR each, one afternoon).
5. **INSP-9** Steam shortcuts export (M).
6. Identify gaps: Meta Quest search, then Epic / itch / Amazon (M).
7. Admin Jinja ports continue one per slice throughout, Tier 1 first.

Everything gated on him (DB engine, history page, scene signal, INSP-26 auth story, SRV-3 socket) stays on the Human Queue and is built only after an answer.
