How to create a theme
{# One place to choose a theme, not two. This page carried its own swatch grid that wrote current_user.preferences.theme — the same thing Preferences does, with the same swatches, so the two could disagree about what was selected and there was no way to tell which one had last won. Preferences is the keeper: it builds its choices from get_installed_themes(), so it already lists uploaded packs as well as presets, and it is where font, icon pack and tile size live too. This page keeps what only it can do — upload, reset, delete. #}
