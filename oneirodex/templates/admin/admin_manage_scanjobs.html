{{ icons.icon('filter', size=22) }} Scanning Filters

Two jobs, one list: strip junk from folder names, or skip whole folders during scans.

How it works

  1. Name tag — stored as plain text (e.g. GOG). Matcher strips -GOG / .GOG from folder basenames before IGDB search. Does not hide folders.
  2. Skip folder — store with dir: prefix (e.g. dir:_MyTools). Folder listing skips matching basenames (case-insensitive fnmatch). Built-in emu/FE skips already exist; this adds yours.
  3. Prefix globs for skips — prefer dolphin* / GOD v*, not *dolphin* / GOD*, so real titles are not skipped.
  4. Skip-dir is defense-in-depth — still point each library at the correct leaf; do not rely on skips to fix a family-root library.

Examples

Name tag GOG

Cleans Title-GOG / Title.GOG for matching.

Skip folder dir:_MyTools

Skips a folder literally named _MyTools.

Skip folder dir:OpenVR*

Prefix glob — skips OpenVR Metrics, not mid-name matches.

Skip folder dir:Tools*

Skips tool trees under a leaf without moving them off disk.

Quick add

Fills the add form — review and save. Does not submit until you confirm.
