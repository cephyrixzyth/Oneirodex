# Aurora surface material sources

> **Doc status:** Reference

The nine bundled 1K JPG maps are unmodified Poly Haven assets under [CC0-1.0](https://polyhaven.com/license). They provide scanned colour, OpenGL normal and roughness data for American Walnut Veneer, Diagonal Parquet and Velour Velvet. Artist/source records, original download URLs, provider MD5, local SHA-256 and byte sizes are in `provenance.json`.

The asset total is 5,520,599 bytes. Runtime uses local `/static/newstyle/rooms/aurora/materials/` URLs only. No remote texture loading, external account or telemetry is required. Room geometry, cabinet construction and the adjacent celestial playfield SVG are original project work; these source credits do not claim the scanned surfaces were authored by Oneirodex.

The source velvet colour scan is red. The material shader preserves its luminance variation and retints it emerald for this room; source image files remain unmodified.

These textures support a visual revision of the unreleased room benchmark. Their presence is not evidence of an accepted polished scene or measured hardware performance.
